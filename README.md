# Correcteur Perso Android — version prototype 0.1

Cette branche isolée sert uniquement à compiler le clavier. Elle ne modifie pas main.

Pour obtenir l'APK :
1. Ouvrir l'onglet Actions de GitHub, workflow « Compiler Correcteur Perso APK ».
2. Ouvrir la dernière exécution réussie.
3. Télécharger l'artefact « CorrecteurPerso-Android-APK ».
4. Dézipper, puis ouvrir app-debug.apk sur Android.
5. Paramètres > Gestion globale > Liste claviers et clavier par défaut > Activer Correcteur Perso.
6. Depuis l'application Correcteur Perso, choisir le clavier dans la liste.

Les corrections fonctionnent hors ligne et sont limitées à quelques règles déterministes.
Le clavier est expérimental : il ne remplace pas encore les fonctionnalités complètes du clavier Samsung.
